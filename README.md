# 認識各國 · Know Different Countries

by **sley** — mobile-friendly page to teach kids **many different countries** in **香港中文** and **English**, plus which of the seven continents each belongs to.

**Live site:** https://kingsleykwan.github.io/country_name/

## Open on a phone

1. Open the live site link above, or open `index.html` locally.
2. Default language is Chinese; tap **EN** to switch to English (choice is remembered).

## How to use

1. On the home screen, choose **常見國家 / Well-known** (default, about 47) or **所有國家 / All countries** (about 200).
2. Tap **全部** for every country in that list, or tap one continent.
3. **Browse** the list — each row shows the real flag. Tap a country to see a large flag and its place on the Earth map.
4. Tap **練習 / Practice** for flashcards (flag image + map below). Tap the card to flip, then Next / Prev / Shuffle.
